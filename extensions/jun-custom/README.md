# Jun's Custom Extensions

This directory contains personal customizations for OpenClaw.

## Purpose

Store custom extensions here to keep them separate from upstream code, making it easier to:

- Maintain personal modifications
- Sync with upstream updates
- Avoid merge conflicts

## Usage

Place your custom extension code in this directory. Extensions should follow the same structure as other OpenClaw extensions.

## Branch Strategy

This directory is tracked in the `custom` branch, which is merged into the `deploy` branch for production use.
