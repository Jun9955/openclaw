# Jun's Custom Skills

This directory contains personal custom skills for OpenClaw.

## Purpose

Store custom skills here to keep them separate from upstream code, making it easier to:

- Maintain personal modifications
- Sync with upstream updates
- Avoid merge conflicts

## Usage

Place your custom skill code in this directory. Skills should follow the same structure as other OpenClaw skills.

## Branch Strategy

This directory is tracked in the `custom` branch, which is merged into the `deploy` branch for production use.
